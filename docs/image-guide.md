# 그림 공통 스타일

모든 그림에 아래 규칙을 적용합니다. 글마다의 요청은 `posts/<글>/images.yaml`에 있습니다.

## 공통

- 밝고 깨끗한 배경(흰색 또는 아주 연한 베이지 `#FAF7F2`).
- 강조색은 **주황 `#F26B1D`** 하나만. 보조색은 진한 남색 `#1F2A44`.
- 그림 안 글자는 **크고 굵게**, 한국어로, 짧게(한 줄 12자 이내). 요청서에 적힌 글자만 넣는다. 철자를 그대로 지킨다.
- 실제 회사 로고·상표·앱 아이콘을 그리지 않는다. 휴대폰은 특정 제품처럼 보이지 않는 일반적인 모양으로.
- 사람이 나오면 50~60대 한국인, 자연스럽고 밝은 표정. 과장된 "노인" 묘사는 하지 않는다.

## 종류별 규칙

### `thumbnail` (대표 이미지)
- 정사각형 1:1, 1080×1080 이상.
- 가운데에 큰 제목 글자, 주제를 보여 주는 단순한 그림 하나.
- 내용이 정확히 가운데 오게(좌우 여백 같게).

### `illustration` (개념 설명 그림)
- 가로 4:3 또는 16:9.
- 비교 그림은 왼쪽/오른쪽 두 칸, 각 칸 위에 이름표.

### `screen-guide` (화면 따라 하기 그림)
- 세로 9:16 휴대폰 화면을 **단순화한 그림**. 진짜 캡처처럼 보이게 꾸미지 않는다.
- 요청서에 적힌 메뉴 이름을 **글자 하나 틀리지 않게** 넣는다. 적히지 않은 메뉴는 회색 막대로 흐리게 처리한다.
- 누를 곳은 주황색 테두리 + 주황 동그라미 번호(①②③).
- 나중에 실제 캡처로 바꿀 수 있으므로, 같은 파일 이름·같은 비율로 만든다.

### `infographic` (정리 도표)
- 가로 4:3. 항목은 3~4개까지. 아이콘 + 짧은 글.

### `capture` (실제 화면 캡처) — 현재 사용하지 않음

- **운영 방침: 직접 캡처는 하지 않는다.** 앱 따라 하기는 본문 단계 설명 + 단계 요약 도표(`infographic`)로 대신한다.
- 공공기관·은행·정부 앱 화면은 **GPT로 흉내 내어 그리지 않는다.** 그린 화면은 실제와 달라 독자를 헷갈리게 하고, 기관 화면을 흉내 낸 것처럼 보일 수 있다.
- 캡처 후 이름·주민번호·계좌·금액·전화번호는 가린다(모자이크나 단색 상자).
- 누를 곳 표시(주황 테두리, ①②)는 캡처 위에 직접 그리거나, 캡처 파일명을 `03-raw.png`로 올리고 표시 작업은 따로 요청한다.
- 파일 이름은 요청서의 `file` 값 그대로 `posts/<글>/images/`에 올린다.

### 사진 공통 원칙 — "우리 상황에 맞는가"가 기준

- **얼굴이 꼭 나올 필요 없다.** 손, 휴대폰, 영수증·통장 같은 물건, 공간 사진이 더 잘 맞는 경우가 많다.
- 사람이 나오면 **50대 중후반~60대 초반 한국인**, 활동적인 일상. "할머니·할아버지" 느낌의 노년 이미지는 쓰지 않는다.
- 한국 상황과 어긋나는 요소는 피한다: 서양인 얼굴 클로즈업, 외국 지폐·간판·글자, 아이폰이 크게 보이는 사진(갤럭시 글일 때).
- 한 글에 2~3장, 그림과 번갈아 배치. 실사(`photo`)와 실사풍(`photo-ai`)을 섞는다.

### `photo` (실사 사진) — 무료 사진 사이트에서

- 쓸 수 있는 곳: **Unsplash(무료 표시된 사진만, Unsplash+ 제외)**, **Pexels**, **Pixabay**. 상업적 이용 가능, 출처는 자동 표기.
- Unsplash 후보에는 `url`(images.unsplash.com 직접 주소)을 꼭 적는다. 다운로드 버튼 주소는 로그인이 필요해 Actions에서 받을 수 없다.
- 주로 쓰는 장면: 휴대폰을 든 손·누르는 손가락, 갤럭시 등 휴대폰 실물, 식탁 위 휴대폰과 서류.
- 쓰지 않는 곳: 유료 스톡(Getty, Adobe Stock, Shutterstock, iStock, Alamy), 언론 보도 사진, 라이선스가 불분명한 검색 이미지. PAKUTASO는 일본어 연락 가능 조건이 있어 쓰지 않음.
- 기관 건물·창구 사진은 자유 이용 조건이 확인된 것만 쓴다(위키미디어 공용 등). 없으면 직접 찍은 사진을 쓴다.
- 사진 속 인물이 특정 제품을 추천하는 것처럼 보이게 쓰지 않음.

### `photo-ai` (실사풍 이미지) — GPT

- 무료 사이트에 없는 **한국적인 장면**을 GPT로 사진처럼 만든다. (예: 한국 아파트 거실에서 50대 후반 부모와 30대 자녀가 휴대폰을 함께 보는 장면)
- 얼굴은 안 보이거나 흐리게 해도 된다. 손과 휴대폰이 중심.
- 휴대폰은 로고 없는 일반 안드로이드 폰. 화면 속 글자는 흐리게(읽히는 가짜 글자 금지).
- 실존 인물·기관 로고·간판 글자를 넣지 않는다.
- 완성본에는 자동으로 "AI 생성 이미지" 표기가 붙는다.

## 파일

- 형식: PNG (또는 JPG/WEBP).
- 이름: 요청서의 `file` 값 그대로 (`01.png` 등).
- 위치: `posts/<글>/images/`
