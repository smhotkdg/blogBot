# 그림 공통 스타일

모든 그림에 아래 규칙을 적용합니다. 글마다의 요청은 `posts/<글>/images.yaml`에 있습니다.

## 공통

- 밝고 깨끗한 배경(흰색 또는 아주 연한 베이지 `#FAF7F2`).
- 강조색은 **주황 `#F26B1D`** 하나만. 보조색은 진한 남색 `#1F2A44`.
- 그림 안 글자는 **크고 굵게**, 한국어로, 짧게(한 줄 12자 이내). 요청서에 적힌 글자만 넣는다. 철자를 그대로 지킨다.
- 실제 회사 로고·상표·앱 아이콘을 그리지 않는다. 휴대폰은 특정 제품처럼 보이지 않는 일반적인 모양으로.
- 사람이 나오면 50~60대 한국인, 자연스럽고 밝은 표정. 과장된 "노인" 묘사는 하지 않는다.

## 종류별 규칙

### `thumbnail` (대표 이미지)
- 정사각형 1:1, 1080×1080 이상.
- 가운데에 큰 제목 글자, 주제를 보여 주는 단순한 그림 하나.
- 내용이 정확히 가운데 오게(좌우 여백 같게).

### `illustration` (개념 설명 그림)
- 가로 4:3 또는 16:9.
- 비교 그림은 왼쪽/오른쪽 두 칸, 각 칸 위에 이름표.

### `screen-guide` (화면 따라 하기 그림)
- 세로 9:16 휴대폰 화면을 **단순화한 그림**. 진짜 캡처처럼 보이게 꾸미지 않는다.
- 요청서에 적힌 메뉴 이름을 **글자 하나 틀리지 않게** 넣는다. 적히지 않은 메뉴는 회색 막대로 흐리게 처리한다.
- 누를 곳은 주황색 테두리 + 주황 동그라미 번호(①②③).
- 나중에 실제 캡처로 바꿀 수 있으므로, 같은 파일 이름·같은 비율로 만든다.

### `infographic` (정리 도표)
- 가로 4:3. 항목은 3~4개까지. 아이콘 + 짧은 글.

## 파일

- 형식: PNG (또는 JPG/WEBP).
- 이름: 요청서의 `file` 값 그대로 (`01.png` 등).
- 위치: `posts/<글>/images/`
