# 원고 작성 규칙

## 독자

- 50~60대 본인, 그리고 부모님 폰을 대신 설정해 드리는 30~40대 자녀.
- "나이가 많으니 초보"라고 가정하지 않는다. 제목과 본문에서 나이를 강조하지 않고, **해결할 문제**를 정확히 쓴다.

## 제목

- 검색어가 앞에 오게: `갤럭시 글자 크게 하는 법｜…`
- 해결할 문제가 드러나게. 30자 안팎.

## 본문 구성 (순서 고정)

1. **도입 2~3문장**: 어떤 불편인지 → 이 글로 무엇을 할 수 있는지.
2. **결론 먼저**: 바쁜 사람은 여기만 읽어도 되게.
3. **기준 표시**: `갤럭시 S24 · One UI 8.5 기준` 처럼 기종과 버전을 쓴다. 메뉴를 못 찾을 때 쓰는 방법(설정 검색)을 함께 적는다.
4. **따라 하기**: 한 단계에 한 동작. 번호 목록. 누를 버튼 이름은 **굵게**, 화면에 보이는 글자 그대로.
5. **완료 확인**: "이렇게 보이면 끝" — 결과로 확인하게 한다.
6. **주의할 점 / 되돌리는 법**.
7. **마무리 질문**: 독자 경험을 묻는 질문으로 댓글을 유도한다. "댓글 남겨 주세요" 같은 직접 요청은 쓰지 않는다.

## 문체

- 존댓말, "~하세요 / ~됩니다". 한 문장은 짧게.
- 영어 메뉴명·전문 용어는 화면에 보이는 한국어 그대로.
- 확인하지 못한 내용은 쓰지 않는다. 기종마다 다를 수 있는 부분은 "기종에 따라 이름이 조금 다를 수 있어요"라고 쓴다.

## 원고 파일 형식 (`post.md`)

```markdown
---
title: 글 제목
slug: 폴더 이름과 같게
tags: [태그1, 태그2]
basis: 갤럭시 S24 · One UI 8.5
checked: false        # 사람이 내 폰으로 확인하면 true
verify:               # 발행 전에 직접 확인할 항목
  - 확인할 내용
---

본문...

{{img:01}}            ← 그림 자리. images.yaml 의 id 와 같게
```

- 소제목은 `##`, 작은 소제목은 `###`.
- 팁 상자는 `> 💡 팁:` 으로 시작하는 인용문.
- 주의 상자는 `> ⚠️ 주의:` 로 시작하는 인용문.
